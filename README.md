EDP Activity 7 – GitHub Collaboration & Branching
Project Overview

This activity demonstrates the use of GitHub for version control, collaboration, branching, and merging changes between two different accounts.

The goal is to practice how developers work together using GitHub repositories, branches, and pull requests.

What I Did in This Activity
1. Created GitHub Accounts
Created a GitHub account using my BU email address.
Created a second GitHub account using another email (Email2).
2. Created Repository
Created a new GitHub repository named EDP Activity 7 under my BU account.
3. Uploaded Project Files
Initialized Git in my local project folder.
Added all files from Activity 6.
Committed and pushed the files to the GitHub repository.
4. Collaboration Setup
Added my second GitHub account (Email2) as a collaborator in the repository.
5. Branching and Updating (Email2 Account)
Cloned the repository using Email2 account.
Created a new branch named update-feature.
Made updates to the project files.
Committed and pushed changes to the new branch.
6. Merging Changes (BU Account)
Switched back to my BU GitHub account.
Reviewed the changes made in the branch.
Created a Pull Request.
Merged the branch into the main repository after review.
Skills Learned
GitHub repository creation
Git push and pull operations
Branch creation and management
Collaboration using multiple accounts
Pull Request workflow and merging changes
